* AI-based information extraction
* Structured JSON output

### Task 3 — Semantic Sentiment & Urgency Analyzer

A customer-support ticket analysis system that uses NLP and semantic analysis to understand customer sentiment and determine the urgency of support requests. The system classifies tickets as positive, negative, or neutral, identifies urgency levels, extracts the core issue, and recommends a support priority.

**Key Features:**

* Positive, negative, and neutral sentiment detection
* High, medium, and low urgency classification
* Core issue extraction
* Recommended support priority
* Hugging Face model integration with local fallback logic
* FastAPI backend with a professional HTML/CSS interface

### Task 5 — Frontend AI Chat Interface

A responsive AI chat interface designed to provide clear and easy-to-understand answers through a conversational UI. The application uses a FastAPI backend and OpenAI integration to generate AI responses, while also providing a demo mode when an API key is unavailable.

**Key Features:**

* ChatGPT-style conversational interface
* OpenAI API integration
* Markdown-based AI responses
* Chat history and clear-chat functionality
* Loading and response states
* Responsive HTML/CSS frontend
* FastAPI backend
* Demo mode for testing without an API key
